# Day 1 – FastAPI Training

## Topics Covered

### 1. FastAPI CRUD Operations (List of Dictionaries)
- Creating API endpoints using GET, POST, PUT, and DELETE methods.
- Handling path and query parameters.
- Performing CRUD operations on a list of dictionaries.
- Request and response handling.
- HTTP status codes and exception handling using `HTTPException`.
- Input validation using Pydantic schemas.

### 2. Database Operations in FastAPI (Persistent Data Storage)
- Integrating SQLAlchemy with FastAPI.
- Configuring database connections.
- Creating database models using SQLAlchemy ORM.
- Defining relationships between database tables.
- Performing CRUD operations using database sessions.
- Using SQLAlchemy queries such as `select()`, `execute()`, and `scalars()`.
- Managing database transactions using `commit()`.
- Implementing dependency injection using `Depends()` for database sessions.
- Understanding persistent data storage compared to in-memory storage.
